# Customer_credit_risk_project
Holistic Data Preparer: End-to-End FinTech Credit Risk Data Pipeline📋 Project OverviewThis project implements an enterprise-grade End-to-End Data Preprocessing and Feature Engineering Pipeline designed for a FinTech credit risk assessment scenario. Acting as a Data Scientist, the goal of this project is to ingest raw, messy consumer data from heterogeneous data sources and transform it into a high-quality, fully processed dataset optimal for training robust Machine Learning models to predict loan defaults.The pipeline natively addresses real-world data science challenges, including missing value imputation, skewness, outliers, mixed variable structures, and multi-categorical data handling.🛠️ Key Technical Capabilities1. Multi-Source Data IngestionIngests and consolidates domain-specific Customer Credit Risk data across multiple sources:Core Transactions: Processed from raw CSV files.Customer Metadata: Parsed directly from structured JSON files.Repayment Histories: Fetched through relational database SQL records.Economic Indicators: Retrieved dynamically via an external API integration.2. Advanced Data Cleaning & ImputationHandles systemic and missing data patterns through a variety of advanced imputation strategies:Numerical Features: Implemented Simple Imputer (Mean/Median), Missing Indicator additions, and iterative multivariate methods such as MICE (Multivariate Imputation by Chained Equations) and KNN Imputer.Categorical Features: Implemented Mode (Most Frequent) Imputation and Category Imbalance fixes.3. Outlier MitigationDetects and bounds heavy-tailed distributions using four alternative statistical thresholds:Z-Score MethodInterquartile Range (IQR) ScalingPercentile CappingWinsorization Techniques4. Advanced Feature Engineering & ArchitectureMathematical Transformations: Addressed skewness on numerical variables using Log, Reciprocal, and Square Root transformations via FunctionTransformer, as well as optimized power transforms via PowerTransformer (Box-Cox & Yeo-Johnson).Categorical Encoding: Applied explicit mapping strategy including Ordinal Encoding for ranked variables, Label Encoding for binary features, and One-Hot Encoding for non-ordinal features.Binning, Discretization & Binarization: Grouped transaction and credit score attributes into algorithmic clusters using Quantile, K-Means Binning, and logical binarization thresholds.Feature Construction: Created structural risk drivers from baseline variables, such as the Debt-to-Income Ratio, Spending-to-Income Ratio, and Temporal attributes extracted from customer bank onboarding timestamps.5. Production-Ready Feature Scaling & IsolationEnforced structural split isolation to strictly avoid data leakage during the engineering pipeline.Scaled data arrays dynamically via a comprehensive evaluation of Standardization (Z-score), Normalization, MinMax, MaxAbs, and Robust Scaling.Streamlined the entire sequence into a production-grade scikit-learn ColumnTransformer workflow.📊 Dataset StructureThe analytical baseline represents a core banking credit dataset mapping diverse customer attributes:Feature GroupFeatures IncludedDemographicscustomer_id, age, gender, region, education_level, employment_typeFinancial Detailsannual_income, loan_amount, loan_purpose, credit_scoreBehavioral Attributesrepayment_history, transaction_count, spending_ratio, join_dateTarget Metricdefault_flag (0: No Default, 1: Default)📈 Final DeliverablesCleaned & Transformed Dataset: A curated, model-ready schema completely insulated against missing values, skewness, and out-of-bound anomalies.Data Quality & Transformation Report: A summary report detailing the operational trade-offs, imputation efficiencies, and feature engineering rationale that drove optimal dataset readiness.
